# Сахара и сахарозаменители

Сладость указана относительно сахарозы: **обычный столовый сахар = 100 %**.

Нулевая гликемическая нагрузка интенсивного подсластителя означает отсутствие значимой углеводной нагрузки, а не автоматически доказанный вред или пользу. Регуляторная безопасность, долгосрочные исходы и роль общей сладости рациона — разные вопросы.
